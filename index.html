How one project runs

Seven steps. Code and AI take the repetitive ones, people make the decisions.

Connect Developer

2

Analyse AI + code

3

Plan AI

4

Build Code

Pages are built as editable content on staging.

5

Check Code + AI

6

Review Human

7

Approve Human

Only an approval moves the work forward.
